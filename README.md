# 打字怪兽 · Typing Monsters

一款霓虹街机风格的网页打字游戏。怪兽带着文字从屏幕上方逼近，在限定时间内打完它的字就能消灭它。支持 **日语、中文、英文**、**BLEACH篇（死神主题，日语）** 以及 **三语混合** 模式。

## 🚀 快速开始

1. 下载 `typing-game.html`
2. 双击文件，用浏览器（推荐 Chrome / Edge / Firefox）打开
3. 选择**输入方式**：
   - **键盘直打**：关闭输入法，直接打罗马字 / 拼音 / 英文
   - **输入法 IME**：用你习惯的输入法打出汉字或假名
4. 选择语言模式，点击「开始游戏」或按 `Enter`

> 单个 HTML 文件，无需联网、无需安装。需要实体键盘，暂不支持手机。

## 🎮 玩法

- 怪兽**一只一只**出现在画面中央，下方显示要打的字和**计时条**。
- 在计时条耗尽前打完就能消灭它，下一只马上登场（右下角会预告 **NEXT**）。
- 时间到怪兽会攻击你，扣 **1 颗心**，并换下一只。共 5 颗心，扣完游戏结束。
- 怪兽会随着时间流逝越变越大，提醒你它快要攻击了。

### 按键

| 按键 | 功能 |
|------|------|
| 字母键 | 输入 |
| `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 再来一局 |

## 🌐 界面语言

开始界面右上角可以切换界面语言：**简体中文、繁體中文、日本語、English**。第一次打开会按浏览器语言自动选择，之后会记住你的选择。
选繁體中文时，中文模式的题目也会显示为繁体字。

## ⌨️ 输入方式

### 键盘直打（默认）
请**关闭输入法**，直接用键盘打罗马字（日语）、拼音（中文）或英文，每按一个键就判定。

### 输入法 IME
画面中间会出现一个输入框，用任何输入法打字，**上屏后**才判定：

- **日语**：微软 IME / Google 日语输入（罗马字输入或かな入力都可以）。打出汉字（如「黒崎一護」）或假名（如「くろさきいちご」）都算对，也可以汉字和假名混着打。
- **中文**：拼音、注音、仓颉、五笔、速成等任何中文输入法，打出正确的汉字即可。
- **英文**：直接打。

**判定标准**（只在输入法模式出现）：
- **宽松**：汉字、假名、拼音都算（例：「犬」打「犬」或「いぬ」都对）
- **严格**：必须打出和题目一样的汉字。打假名会提示「要打汉字！」

中文题目简体、繁体都接受，用注音 / 仓颉打出繁体字也算对。

**选字小提示（微软日语 IME）**：边打边出现、写着「Press Tab to select」的是**预测候选**，按数字键不会选字。按 `Tab` 或 `↓` 进入列表后再选；或者按 `空格` 转换，出现转换候选后就能按数字键选。

说明：
- 输入法要选字、转换，所以中日文词语的限时比键盘直打多 30%。
- 上屏的字不对会扣连击，输入框里错的部分会被自动删掉。
- 两种输入方式的最高分分开记录。
- 输入法模式可以用手机或平板的屏幕键盘玩。

## 🌏 语言模式

| 模式 | 显示 | 输入方式 | 示例 |
|------|------|----------|------|
| 日本語 | 汉字 + 假名 | 罗马字 | 学校 → `gakkou` |
| 中文 | 汉字 | 拼音（不带声调） | 熊猫 → `xiongmao` |
| English | 单词 / 短句 | 直接输入 | `dragon` |
| BLEACH篇 | 死神人物 / 斩魄刀 / 卍解 / 鬼道 | 罗马字 | 月牙天衝 → `getsugatenshou` |
| 混合 | 三语随机 | 按对应语言输入 | — |

### 日语罗马字规则

- 支持多种写法：`shi`/`si`、`chi`/`ti`、`tsu`/`tu`、`fu`/`hu`、`ja`/`zya`/`jya` 等
- 促音「っ」：双写下一个辅音（`kippu`、`matcha`），或单独打 `xtu` / `ltu`
- 拗音可拆开打：「じゃ」= `ja` 或 `jixya`
- 「ん」：一般打 `nn`；后面接辅音（n、y 除外）时可只打 `n`
  - 例：「こんにちは」要打 `konnnichiha`
- 长音「ー」打 `-`

### BLEACH篇

日语模式的死神主题版，规则与日语相同，词库收录约 100 个：

- **术语**：死神、虚、卍解、始解、霊圧、瞬歩、破面、十刃……
- **人物**：黒崎一護、朽木ルキア、朽木白哉、日番谷冬獅郎、更木剣八、藍染惣右介、ウルキオラ……
- **地点**：尸魂界（ソウルソサエティ）、虚圏（ウェコムンド）、瀞霊廷、空座町……
- **斩魄刀 / 招式**：千本桜、氷輪丸、蛇尾丸、鏡花水月、流刃若火、月牙天衝、黒棺、六杖光牢……
- **BOSS**：千本桜景厳、大紅蓮氷輪丸、残火の太刀、最後の月牙天衝……（出现时显示「卍解 BANKAI!」）

> 部分词汇按作品中的特殊读音输入，例如「尸魂界」打 `sourusosaethi`、「滅却師」打 `kuinshi-`，开启输入提示可以看到读音。

### 中文拼音规则

- 不带声调，直接连写：生日快乐 → `shengrikuaile`
- ü 用 `v` 代替：绿色 → `lvse`、旅行 → `lvxing`

## 📈 难度与计分

### 难度递增

- 每消灭 **8 只**怪兽升 1 级
- 等级越高：每只怪兽的限时越短
- 词语逐渐变长：单字 → 词语 → 成语 / 长词 → 句子
- 每到 **5 的倍数等级** 出现 **BOSS**（长句 / 绕口令）

### 计分

- 基础分 = 字数 × 10 × 等级加成
- **时间奖励**：打得越快加分越多
- **连击倍率**：每连击 10 次倍率 +0.5，最高 ×4
- 打错一个字母，连击归零
- **PERFECT**：一只怪兽零失误打完，额外加分
- 击败 BOSS：**3 倍分数** 并回复 **1 颗心**

### 结算数据

游戏结束后显示：总分、到达等级、消灭数、最高连击、准确率、每分钟按键数、存活时间。
每个模式的最高分会单独保存在浏览器本地。

## 🎵 BGM

每个模式都有**原创配乐**，在浏览器里实时合成，不需要额外的音乐文件：

| 模式 | 风格 |
|------|------|
| 日本語 | 和风：日本都节音阶、琴、太鼓、钲 |
| 中文 | 中国风：五声音阶、古筝刮奏、二胡、木鱼 |
| English | Synthwave / 8-bit 电子 |
| BLEACH篇 | 暗黑 J-Rock：失真吉他强力和弦、三味线、摇滚鼓 |
| 混合 | 每隔几小节在和风、中国风、电子之间切换 |

- 等级越高，节奏越快，乐器层次越多；BOSS 出现时音乐会更激烈。
- 每局的旋律都是随机生成的，不会完全一样。

### 自定义 BGM

在开始界面点 **🎵 自定义 BGM**，可以给当前模式选一首**你电脑上的音乐文件**（mp3 / m4a / ogg / wav 等）。

- 音乐只保存在你自己的浏览器里，不会上传到任何地方。
- 每个模式可以设不同的歌，点 **✕ 恢复原创** 换回原创配乐。
- 请不要把有版权的音乐文件上传到公开的 GitHub 仓库。

## ⚙️ 选项

- **音效**：开 / 关
- **BGM**：开 / 关，可调音量
- **显示输入提示**：在日语和中文模式下显示罗马字 / 拼音提示，已输入部分高亮。关闭后更有挑战性。

## ❓ 常见问题

**按键没有反应？**
请关闭输入法。如果画面底部出现红色提示「请关闭输入法」，说明输入法仍处于开启状态。

**最高分不见了？**
最高分保存在当前浏览器中。换浏览器、使用无痕模式或清除浏览器数据后会重置。

**切换窗口后游戏停住了？**
离开窗口时游戏会自动暂停，按 `Esc` 或点「继续」即可。

## 🛠 自定义词库

用文本编辑器打开 `typing-game.html`，找到 `词库` 部分：

```js
const JA = { t1: [["猫","ねこ"], ...], t2: [...], t3: [...], boss: [...] };  // [显示, 平假名读音]
const ZH = { t1: [["猫","mao"], ...], ... };                                // [汉字, 拼音]
const EN = { t1: ["cat", ...], ... };                                       // 单词
const BL = { t1: [["死神","しにがみ"], ...], ... };                          // BLEACH篇，格式同日语
```

- `t1` 短词、`t2` 中等、`t3` 长词、`boss` BOSS 句子
- 日语读音请用**平假名**，长音写 `ー`
- 中文拼音用小写、不带声调、ü 写成 `v`

保存后重新打开文件即可生效。
