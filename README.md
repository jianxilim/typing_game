# 打字怪兽 · Typing Monsters

一款霓虹街机风格的网页打字游戏。怪兽带着文字从屏幕上方逼近，在限定时间内打完它的字就能消灭它。支持 **日语、中文、英文** 以及 **三语混合** 模式。

---

## 🚀 快速开始

1. 下载 `typing-game.html`
2. 双击文件，用浏览器（推荐 Chrome / Edge / Firefox）打开
3. **关闭输入法**（切换为半角英文）
4. 选择语言模式，点击「开始游戏」或按 `Enter`

> 单个 HTML 文件，无需联网、无需安装。需要实体键盘，暂不支持手机。

---

## 🎮 玩法

- 怪兽从上方出现，逐渐向下移动；头顶的**时间条**显示剩余时间。
- 在怪兽碰到底部**红色虚线**之前打完它的字即可消灭。
- 敲下第一个字母会**自动锁定**一只匹配的怪兽（优先锁定最紧急的）。
- 怪兽冲到底线会扣 **1 颗心**，共 5 颗心，扣完游戏结束。

### 按键

| 按键 | 功能 |
|------|------|
| 字母键 | 输入 |
| `Backspace` | 取消当前锁定 |
| `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 再来一局 |

## 🌏 语言模式

| 模式 | 显示 | 输入方式 | 示例 |
|------|------|----------|------|
| 日本語 | 汉字 + 假名 | 罗马字 | 学校 → `gakkou` |
| 中文 | 汉字 | 拼音（不带声调） | 熊猫 → `xiongmao` |
| English | 单词 / 短句 | 直接输入 | `dragon` |
| 混合 | 三语随机 | 按对应语言输入 | — |

### 日语罗马字规则

- 支持多种写法：`shi`/`si`、`chi`/`ti`、`tsu`/`tu`、`fu`/`hu`、`ja`/`zya`/`jya` 等
- 促音「っ」：双写下一个辅音（`kippu`、`matcha`），或单独打 `xtu` / `ltu`
- 拗音可拆开打：「じゃ」= `ja` 或 `jixya`
- 「ん」：一般打 `nn`；后面接辅音（n、y 除外）时可只打 `n`
  - 例：「こんにちは」要打 `konnnichiha`
- 长音「ー」打 `-`

### 中文拼音规则

- 不带声调，直接连写：生日快乐 → `shengrikuaile`
- ü 用 `v` 代替：绿色 → `lvse`、旅行 → `lvxing`

## 📈 难度与计分

### 难度递增

- 每消灭 **8 只**怪兽升 1 级
- 等级越高：同屏怪兽越多、出现越快、限时越短
- 词语逐渐变长：单字 → 词语 → 成语 / 长词 → 句子
- 每到 **5 的倍数等级** 出现 **BOSS**（长句 / 绕口令）

### 计分

- 基础分 = 字数 × 10 × 等级加成
- **时间奖励**：打得越快加分越多
- **连击倍率**：每连击 10 次倍率 +0.5，最高 ×4
- 打错一个字母，连击归零
- 击败 BOSS：**3 倍分数** 并回复 **1 颗心**

### 结算数据

游戏结束后显示：总分、到达等级、消灭数、最高连击、准确率、每分钟按键数、存活时间。
每个模式的最高分会单独保存在浏览器本地。

## ⚙️ 选项

- **音效**：开 / 关
- **显示输入提示**：在日语和中文模式下显示罗马字 / 拼音提示，已输入部分高亮。关闭后更有挑战性。

## ❓ 常见问题

**按键没有反应？**
请关闭输入法。如果画面底部出现红色提示「请关闭输入法」，说明输入法仍处于开启状态。

**最高分不见了？**
最高分保存在当前浏览器中。换浏览器、使用无痕模式或清除浏览器数据后会重置。

**切换窗口后游戏停住了？**
离开窗口时游戏会自动暂停，按 `Esc` 或点「继续」即可。

## 🛠 自定义词库

用文本编辑器打开 `typing-game.html`，找到 `词库` 部分：

```js
const JA = { t1: [["猫","ねこ"], ...], t2: [...], t3: [...], boss: [...] };  // [显示, 平假名读音]
const ZH = { t1: [["猫","mao"], ...], ... };                                // [汉字, 拼音]
const EN = { t1: ["cat", ...], ... };                                       // 单词
```

- `t1` 短词、`t2` 中等、`t3` 长词、`boss` BOSS 句子
- 日语读音请用**平假名**，长音写 `ー`
- 中文拼音用小写、不带声调、ü 写成 `v`

保存后重新打开文件即可生效。
